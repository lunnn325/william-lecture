# William Lecture · V1

Native iOS Operate/Read. The user's supplied transcript reference and Apple-native restraint are the pinned direction. This session builds directly in SwiftUI; this is not a standing image-generation preference.

The signature is a bilingual reading rhythm: quiet English, larger Chinese, a small audio timestamp and a discreet bookmark. No transcript cards, waveform dashboard or translation source badges. System backgrounds and SF text styles support dark mode and Dynamic Type; system teal is the sole interactive tint. Recording uses a quiet dot and a literal state label.

Three top-level tabs: recording, records, settings. Recording becomes immersive during an active session, using a native inline navigation bar and a safe-area bottom control shelf. Course selection and focused tasks use sheets. Transcript rows keep their UUID across local/GPT replacement. User scrolling suspends follow; a single return-to-latest action restores it. No replacement animations.

Chinese uses title2 medium, English subheadline secondary, timestamps caption2 monospaced digits. Phone gutters 22 pt; iPad reading column max 760 pt. Row separation 24 pt, no enclosing boxes. Controls have at least 44 pt targets. Bottom controls adapt to accessibility sizes instead of truncating labels.

History uses native lists and search; details combine timeline playback with the same caption typography. Export and settings use native forms. Live faults appear once with a short recovery message and access to diagnostic detail. Empty states explain the next action without inventing lecture data.
