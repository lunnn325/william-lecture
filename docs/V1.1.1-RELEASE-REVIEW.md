# William Lecture 1.1.1 使用问题修复

版本 1.1.1 / build 11；保持 bundle ID、录音写盘、音频时间轴和原文存储兼容，不使用 Impeccable。

## 修复

- 短句、空响应和拒绝响应曾中止整条 GPT 队列，其他句子一直显示处理中。现在单段内容错误隔离；不完整响应有限重试；网络/限流错误保留队列并增加有限自动唤醒。拒绝内容不会伪造译文。
- Apple 本机翻译单个空结果不再禁用整节课的本机译者。模型确实不可用、超时且任务尚未退出时仍保守降级。
- 读取 `output_text.done` 与成功 `response.completed` 的完整正文，避免没有观察到 delta 的短响应被误判为空；失败/不完整响应不能成为最终版。[Responses 事件说明](https://developers.openai.com/api/reference/resources/responses/streaming-events)
- 翻译字段合并加入可选的写盘顺序编号，防止迟到的处理中快照覆盖已经失败或完成的状态。旧 JSON 可直接读取。
- 向上阅读只停止自动滚动，新字幕仍加入列表；自然滚回底部恢复跟随。当前 partial 不再因阅读旧句而隐藏。主动加载更早页可增加阅读窗口，仍保留最新内容。
- 首页合并课程记录和小型麦克风按钮；录课时才显示工作区。停止后进入该节详情，返回首页显示记录，避免遗留旧字幕。
- 长按直接打开该句笔记，冻结课堂/句子身份；笔记编辑器按笔记 ID 初始化，连续编辑不同句子不复用旧内容。单击选择、双击标记保留。
- 笔记数/摘要预览在存储 actor 内只合并对应字段，避免读写之间的并发更新覆盖停止状态、时长或手动名称。
- 正常静音尾段不再被自动标记为丢失转写。真实 partial 尾段、Speech 故障和已记录输入缺口仍进入补处理。
- 已安装 Speech 模型直接使用，不把可选安装请求一律解释为缺模型；新课堂保存录课时 locale，课后补转写复用它。[Apple 资源状态接口](https://developer.apple.com/documentation/speech/assetinventory/status(formodules:))
- 音频补转写失败时继续处理已有英文和缺失中文，单独保留未补范围与原因。详情错误收起显示，导出注明缺失；原音频不变。既有 Speech 失败的已申请任务在升级启动时恢复，未申请整理的旧课堂不自动上传。准备英文模型后可重试未补音频。

## 验证

本地 diff/密钥检查已通过。Release 构建、核心回归、iPhone/iPad 使用流程正在标准 macOS Actions 验证；完成后填写结果与 IPA 校验信息。

新增针对性检查覆盖短句/空响应隔离、不完整响应重试、乱序状态回调、静音尾段、补转写警告导出，以及录音中长按不同旧句、自然滚动到新增字幕、停止后首页切换。保留原有暂停时间轴、回放、导出、横竖屏、深浅色与首次启动检查。

## 真机复测

用同一段 1–2 分钟英文音源，包含 `Leon?`、`Yes, Mother?`、`What are you doing?` 和结尾静音：检查短句是否补齐；上翻后继续播放，再自然滚到底部；长按两句核对笔记原文；停止后检查详情和首页。随后测试断网恢复、模型准备、iPad 横竖屏与导出。

Windows/模拟器不能验证真实 Apple 模型、API 权限或延迟。若模型确实被系统移除仍须在设置准备；断网、账户错误或真实拒绝响应会保留英文与原录音并明确显示待处理/失败，不能保证凭空补出中文。此前来电测试仍未完成。
