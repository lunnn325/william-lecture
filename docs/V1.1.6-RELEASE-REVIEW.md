- 独立短词扩充 right、what、why、really、well 等；仅匹配完整片段，保留英文，结合标点和邻近语境给出中文。整句含有这些词仍提交 GPT，不机械丢弃。

- 实时字幕及日常导出优先有效修订英文；原始转写导出仍提供原文。迟到本机/旧 revision 回调不能覆盖英文中文最终配对；查词期间仍冻结当前选词，不打断阅读。
- 小窗移到导航栏的 56×32 可见视频源，不再占用底部 224×126 区域。补首帧、就绪观察、限时启动等待及窗口附着检查；切换 App 自动尝试，图标可手动重试。录音开始前使用 `playAndRecord` / 默认模式，保留输入采集参数；小窗不在录音中改变音频会话，不播放静音音频或申请摄像头。返回前台停止小窗但保留字幕和录音。
- 录课顶部新增手动摘要图标，按点击时的转写快照生成临时摘要，可复制。独立客户端，不占字幕请求并发名额；关闭或换课堂取消旧结果。真实用量归入“手动摘要”，不计入课后自动处理 250k 预算。
- 设置新增“字幕显示”：中英独立字号“小 / 默认 / 大”、深浅“浅 / 默认 / 深”、即时预览与恢复默认；自动保存并支持深色模式和动态字号。
- 课后某句修订改变数字/否定或返回空内容时，仅丢弃该句修订及其中文，保留原文和已有有效译文，记录诊断，继续摘要与导图。启动自动恢复旧版本因这一错误停止的既有任务；不为未触发整理的旧记录自动创建任务，预算限制不变。
