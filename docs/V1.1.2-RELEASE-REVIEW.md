# William Lecture 1.1.2 · 删除与录音清理

版本 1.1.2 / build 12；保持 bundle ID、现有记录和录音/字幕链路兼容。

## 使用

- 首页卡片长按或详情右上角菜单：清理录音、删除记录。详情保留改名。
- 删除记录经确认后永久删除该课堂及 App 内导出文件；不设回收站。
- 清理录音删除 CAF/M4A，保留文字、笔记、摘要、导图、时长、时间戳、diagnostics 和用量。详情显示“录音已清理”，文字导出仍可用。
- 尚未完成的课堂也能清理，确认框说明未补转写内容无法恢复。已有文字的后续处理仍可继续。
- 已导出到外部位置的副本、课程配置、语言模型和 Keychain 不受影响。
- 录音/暂停、保存、笔记写入、导出或分享期间不允许删除；取消确认不改文件。

## 存储与任务

- 删除先写持久化 UUID 标记，再移除课堂目录；标记不含课堂内容。所有课堂写入与导出入口校验存在性和删除标记，防止缓存、迟到响应及旧 metadata 重建记录。
- 可选音频存储状态记录清理中/已清理。旧 JSON 直接读取；旧快照不能把已清理音频恢复为可用。
- 启动时继续未完成的删除/清理。失败保留重试入口，不能把未释放空间报告为已释放。
- 目标课堂处理队列暂时挂起，录音回放失效；删除取消该课堂译者。清理后保留真实缺口，停止音频补转写，已有英文可继续翻译/生成摘要。
- 所有删除路径限制在对应课堂目录，音频清理只处理该目录及 Exports 中的 CAF/M4A，拒绝目录符号链接越界。
- 重复导出复用已有 Exports 目录。确认与失败重试使用同一提示入口，菜单改名保留独立确认。
- 本版生成的导图图片归入课堂 Exports，整节删除一并移除。早期版本未关联课堂的临时图片不批量删除，由系统管理。
