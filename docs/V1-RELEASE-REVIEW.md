# William Lecture V1 使用流程审查

版本 1.0.0 / build 9。录音、Apple Speech、本机翻译、GPT revision 校验和替换、正式文字稿导出沿用 0.0.8；bundle ID、Keychain 和 Documents/Sessions 不变。

## 本轮交付

- 录课 / 记录 / 设置三个入口；录课期间隐藏 Tab 栏，中文为主、英文辅助，底部固定时长、暂停、停止、标记。
- 自动跟随最新；手动回看冻结行成员，译文原位更新。跟随窗口 180 段，读取更早页上限 360 段。
- 轻点标记、双击或长按写笔记。独立增量日志及 TXT/Markdown 笔记导出，不改课堂原文。
- 历史搜索、课程详情、整节时间轴与 ±15 秒回放；录课期间禁用播放和音频路由改变。
- 统一导出表单：英/中/双语、TXT/Markdown，可带笔记、M4A、diagnostics。
- 设置保留课程、口音、Key、模型、本机模型准备；工程状态和演示模式移入诊断。

## 主动修复的使用边界

- 停止后的 Speech/写盘收尾期间锁定课程和设置，防止切换课程清空正在保存的课堂。
- 新课程清空旧课堂展示，不把上一节字幕挂在新课程名下；旧课堂仍从历史访问。
- 停止需要确认，可取消；连续开始受原有生命周期 busy/active 守卫保护。
- 字幕窗口只更新有效 revision，已完成中文不回退；回看时新增内容不挤入窗口。
- 笔记保存失败留在编辑器并显示原因；取消修改需确认。
- 回放准备失败不保留上次播放索引；旧回调检查 player 身份，开始录课后停止播放器。
- 录课时设置可查看、可关闭，不能更改当前链路；空 Key 不删除已保存 Key，删除有独立确认。
- 旧课堂没有 notes.jsonl 时正常读取；取消标记保留已有文字笔记，残缺尾行可恢复。
- 更改导出语言或文件选项后，旧分享结果立即失效，必须重新生成；生成期间锁定选项，避免选项与实际文件不一致。
- 开始和停止收尾明确显示「正在准备录音」「正在保存」，不提前宣称录音已经开始或课堂已保存。
- 即使本机中文与 GPT 最终中文完全相同，状态、revision 和显示诊断仍会更新。
- 操作色改为按明暗模式适配的深青/浅青，辅助英文和状态使用独立中性色；Key、模型和新课程输入提示也显式使用该文字色。
- 修复旋转后跟随标志仍为开启、画面却停在较早字幕的问题：尺寸稳定后重新定位底部，检查跟随状态、取消和课堂身份；回看时不执行。

## 真机仍需验证

模拟器只验证交互、离线夹具与文件输出，不代表真实 Speech/Translation/GPT 延迟、质量或功耗。DEBUG 夹具目录隔离，Release 不包含夹具。

第一步用同一 Apple ID 覆盖安装，不卸载：确认旧记录和 Key，选择课程录 5–10 分钟；标记/写笔记，上滑回看后等待 GPT 更新，再回到最新。暂停 30 秒后恢复，核对顶部、字幕和回放共用音频位置。停止后回听、拖动、导出并立即开始下一节。

接着验证断网、本机模型缺失、后台返回、横屏与系统大字号。来电中断仍需实际 iPhone 测试；两至三小时的发热、电量和系统挂起行为无法由加速文字模拟证明。字幕变长会自然增加行高，实际阅读位置应特别留意。音频仍为原始分段 PCM，空间占用及当前未关闭片段的意外退出恢复沿用既有风险。
