# William Lecture 1.1.4 / build 14

英文选词与系统词典。保持 bundle ID、录音管线、字幕队列、时间轴和既有 JSON 数据兼容。

## 改动

- 录课页与详情全文使用只读、可选、内部不滚动的 UITextView；实际连续选区提供词典、发音、翻译、解释和复制。最多 10 词 / 120 字符，校验 UTF-16 范围，不截断或回退到整句。
- 英文只处理原生选词，中文和时间保留整句操作。正在选择的英文保持快照，其他字幕继续更新；退出后保持阅读位置，手动滚到底部或点击箭头恢复跟随。
- 词典使用系统定义界面；发音只在暂停或结束后运行，开始/恢复前同步停止，不使用修改录音会话的结束回调。
- 手动本机翻译使用独立已安装模型会话，4 秒截止时间，不下载、不转 GPT，底层未退出前不释放并发位置。
- 解释沿用设备 Keychain、当前模型与 Responses 流式解析、连接。选词和句子快照仅作为输入数据，结果只临时查看/复制。取消、换词、换课堂或离开后撤销请求身份。
- 查词用量单独计入课堂总量，响应 ID 去重；未知用量仍明确保留，不计入课后 250k 预算。不建立查词历史或自动保存笔记。
