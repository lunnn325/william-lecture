# William Lecture 1.1.8 / build 18

本轮把现有摘要、思维导图和录音中的当前摘要接入原生交互。录音、Speech、本机翻译、实时修订、时间轴、课后处理和原文存储不变。

- 摘要支持逐项展开／折叠、全部展开／折叠；概念、术语、公式、论证和例子沿用已有内容树。时间点可回到原文，长按时间点可选择同一节点的其他来源。
- 导图使用原生曲线连接分支，支持单分支折叠、整体折叠、拖动、捏合／按钮缩放、重置、全屏查看。点节点查看正文及全部引用原文；点时间点跳回对应文字并定位音频，录音已清理时仍可定位文字。关闭全屏／节点详情不修改录音状态。
- 图片分享始终包含全部分支，不受当前折叠和缩放影响；既有 Markdown 摘要导出保留完整内容。
- 手动摘要改为有来源 ID 的结构化快照，同一结果可切换摘要／导图，无需第二次生成。刷新只在用户点击时执行；刷新中或失败时保留上一份快照。复制包含完整层级和时间点。
- 手动摘要只使用已保存的定稿文字，显示覆盖时间，未定稿尾句不作为引用。来源 ID、唯一节点 ID、深度和节点数均校验；换课堂／关闭后迟到结果无效。回到录课原文时固定阅读位置，手动回到底部或点箭头恢复跟随；录音与新字幕继续。
- 浏览交互不调用 API；手动刷新沿用现有模型、独立连接池、Keychain 与查账方式，计入「手动摘要」，不占课后 250k 自动处理预算。旧记录无需迁移或重新生成，展开状态只保存在界面内存中。

采用已有 Responses 严格结构化输出，未引入网页脚本或独立可视化 API。[OpenAI 结构化输出说明](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses)。可调参数的经济／金融模拟不在本轮范围。

## 验证

新增针对性验证：来源隔离、重复 ID、空来源、树深度与数量限制、折叠后内容／复制完整性、mock 快照；扩展现有 iPhone／iPad 流程，检查摘要折叠、分支折叠、节点详情、缩放重置、全屏、来源跳转与录音继续。测试不调用真实 Apple 翻译或 GPT。

最终 CI、Release 构建及 IPA 校验结果交付时补充。真机复测：录课中生成／刷新摘要与来源跳转，长摘要导图的拖动／捏合，iPad 横竖屏，清理音频后的文字来源跳转与完整分享。
