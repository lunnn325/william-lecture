# William Lecture 1.1.5 / build 15

后台翻译恢复与字幕小窗。保留 bundle ID、原始录音、Speech 时间轴、修订身份校验、Keychain 及既有记录。

## 修复

- 轻滑退出手势产生的 `inactive` 不再当成后台清空字幕。真正进入后台也保留当前 partial、revision 和本机中文；录音的后台执行期间继续本机及 GPT 翻译。本机后台 partial 合并到一个待处理项，更新频率降低到约每秒一次，稳定段仍公平排队。
- 返回前台恢复暂时不可用的本机译者、GPT 请求及过期重试计时器。真实网络/429/5xx 使用逐渐延长、最长五分钟的恢复等待；不再两轮后永久休眠。无效配置及手动取消仍需人工处理，不静默更换模型。
- 已失败的空/未完成 GPT 响应在返回时重新排队；原有完整本机版本在 GPT 完成前保留，最终响应照原有身份校验一次替换。已知独立填充词使用现有保守本机草稿，不依赖暂时不可用的模型。
- 前台从持久化快照补取最新字幕及已加载的历史行；修复后台回调被 SwiftUI 合并后，磁盘已有最终中文而页面仍为旧草稿/省略号。刷新不主动恢复跟随、不清掉选择、不滚动到旧句。
- 空队列状态同时检查缺失最终中文和本机独立短词；不能再把失败片段掩盖成“翻译已跟上”。诊断新增 `translation_foreground_resume`、`translation_queue_idle` 及实际缺口数。
- 保护原生选词：查词期间同时固定英文和文字属性。避免 SwiftUI 动态颜色比较不一致引发重复 `attributedText` 赋值，清掉 UIKit 选区或原生菜单；退出查词后更新主题和字号。

## 字幕小窗

- 设置中开关，默认关闭。启用后录课控制区显示轻量字幕视频预览和画中画图标；切换 App 使用 Apple 系统 PiP，返回 WL 关闭小窗。最新英文、单一中文、课程、录音状态和时长写入视频帧，最多约每秒两帧。
- 内容由控制器直接更新，不依赖后台 SwiftUI 刷新。原生暂停/继续与录课状态一致；关闭小窗不停止录音。没有录课或关闭开关即停止小窗和渲染任务；下一课堂重新绑定显示层，防止显示旧课堂。
- 不修改录音的 AVAudioSession、不播放合成音频、不申请摄像头或私有悬浮窗权限。锁屏不显示小窗；后台处理依赖系统允许的音频执行时间，暂停后系统挂起时保留队列，返回前台继续。小窗不能绕过 iOS 生命周期限制。
- AVKit 非主线程的同步播放状态查询使用锁保护的简短快照，其余回调回到主线程；不从框架线程直接访问录课/UI 状态。
- 接口依据：[Apple 画中画自动启动](https://developer.apple.com/documentation/avkit/avpictureinpicturecontroller/canstartpictureinpictureautomaticallyfrominline)、[Sample Buffer 内容源](https://developer.apple.com/documentation/avkit/avpictureinpicturecontroller/contentsource-swift.class/init(samplebufferdisplaylayer:playbackdelegate:))、[实时内容时间范围](https://developer.apple.com/documentation/avkit/avpictureinpicturesamplebufferplaybackdelegate/pictureinpicturecontrollertimerangeforplayback(_:))、[已安装本机翻译会话](https://developer.apple.com/documentation/translation/translationsession/init(installedsource:target:))。
