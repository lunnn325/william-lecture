# V0 Hardening · 0.0.5

以 0.0.4 为基线，完成一轮有边界的可靠性加固。未调用真实 GPT、未申请新 Key、未修改签名；保留现有 Speech 配置与用户模型，未做视觉精修。

## 主动发现与修复

- 暂停/停止可能丢弃已接收的排队音频：先关闭采集入口，再排空已接收写入，最后关闭 CAF；恢复时拒绝旧一轮回调。
- 音频索引写盘失败原来会停止录音：改为显示警告，原音频继续。索引记录真正首帧时间；健康检查不再每秒遍历全部旧音频文件。
- 旧 Speech/录音/翻译回调可能污染下一节课：按课堂与实例过滤，操作串行；“补翻译”忙碌时拒绝重复操作，取消旧任务后才能换 worker。
- Speech 超时原来可能仍等待未合作退出的任务：改用独立截止时间，停止先关闭录音；超时标记英文缺口，晚到结果丢弃。停课时长排除 Speech 收尾等待。
- 手动取消翻译后联网会意外重启：区分手动取消和暂时网络失败；网络恢复仅自动唤醒后者。保留两段并行、有限重试和磁盘待处理队列。
- 异常退出恢复只看最后一段，可能漏掉中间缺失英文：检查范围覆盖，补回已保存 final；损坏的一堂课不阻断其他课恢复。重开时间不计入录课时长。
- 历史课堂音频列表可能过时，回放自动续播可能切换新录音的音频模式：重新核对磁盘、约束索引/分页、采集中停止回放及续播。
- 原来无整堂 M4A、分享的是仍在变化的 diagnostics：增加分块流式 CAF→AAC M4A，已知暂停/中断空档填静音；坏片段或索引列出的缺失片段导致明确失败，不把缺失音频冒充暂停，不发布半成品、不动原文件。TXT/Markdown/diagnostics 使用独立快照文件，录音保存完成后才能生成。
- Keychain 更新先删旧 Key 存在丢凭证风险：优先原位更新。诊断字段统一脱敏；CI 检查受跟踪文件中的 Key/私钥/凭证文件，不打印命中内容。

## 已知风险与真机边界

- 模拟测试不能证明 iPhone 锁屏/后台、来电、蓝牙路由、模型下载、功耗/发热、实际字幕准确率或真实 API 延迟。快速点按的入口保护已审查，系统权限弹窗及音频时序须在设备验证。
- 系统强杀时当前未关闭 CAF 尾部能恢复多少由 Apple 文件/系统写入决定；原文件保留，无法读取则回放/合并报错。未实现自动重转原始音频；Speech 失效时英文仍可能缺失。
- 完整损坏的日志不自动修补或伪造；报错并保留原文件。损坏 metadata 的课堂暂不进入列表，启动会提示，通过文件共享可取回。
- 不合作的 Apple 任务无法强行终止线程；截止时间保证控制流程返回，真实资源释放仍需真机观察。
- M4A 为 48 kHz 单声道 AAC 96 kbps，CAF 保留原始声道；索引缺失的旧片段按顺序拼接，不能重建未知空档。导出需要额外空间，长导出暂阻止开始新录音；快照生成后新译文需重新导出。
- Speech final 若出现不同结束时间的重叠，保留内容并记录 `speech_final_overlap`；不猜测删词。实际需从 diagnostics 判定。
- 模拟使用注入译者；没有真实 API 费用与手机内存数据。未执行 Sideloadly 安装/续签，未接触 Apple ID 或设备 Key。
- 当前大字幕栏在请求失败/取消后可能暂留先前流式文字；以系统状态与文字稿 pending/failed 为准，未完成译文不按成功结果持久化/导出。这一轻微显示问题留待真机反馈，不继续扩 UI。

## 真机反馈与 0.0.6 暂停计时修复

用户反馈 0.0.5 除来电未测外，其余已测项目通过；唯一发现的问题是暂停后界面计时仍增长。原因是同一 elapsed 同时承载课堂时间轴与录音显示时长，timer 和音频 meter 都会写入包含暂停的 offset。

0.0.6 的主计时只读取实际采集 PCM 的累计秒数；暂停/停止后从录音队列读取完整尾部计数，恢复继续累加，旧回调不能把数字倒退。metadata 新增可选 recordedDuration，旧课堂保持可读；异常恢复可从已有 health 数据恢复累计采集时长。字幕、诊断、回放/M4A 继续使用原时间轴，不改变既有暂停空档或文本位置。来电仍需真机验证。

## 0.0.7 字幕与录音时间轴统一

用户发现 0.0.6 最近 30 段仍包含暂停时间，与顶部时长不一致。上次修复只覆盖了顶部，未统一整条时间轴。新课堂现在以成功写入 PCM 的累计帧数生成 Speech 输入位置，顶部、字幕、历史、TXT/Markdown 和 M4A 共用实际录音秒数；暂停/中断不增加音频位置，已保存 CAF 连续回放与 M4A 直接串接，缺口继续明确标记。停止时不改回墙钟时长。每次关闭音频追加持久化累计秒数，恢复也保留这一时基。

真实采集日期独立保存在 final/segment，ASR 和 GPT 延迟根据该日期计算，不把课间暂停当成等待。稀疏时钟锚点允许约 50 ms 映射误差；真实延迟和 Apple 输出范围须真机核对。没有新日期的新格式模拟片段不伪造端到端延迟。旧 metadata 没有 timeline 标记时继续使用旧位置与暂停空档，历史及导出明确标识，不自动改写旧课堂。修复后应新建课堂测试。

新增回归覆盖 30 秒暂停后的片段位置/文字导出、跨暂停真实 capture 日期、三小时连续时间映射不随每个 PCM 包增长、关闭片段计数恢复、GPT 延迟不混入暂停，以及不同采样率/声道音频在录音轴上的 M4A 定位；旧带空档音频和旧 metadata 测试继续保留。
